# Portfolio Architecture

Domain terminology and ubiquitous language for the newESP software engineering portfolio.

## Language

### Visual & Structure

**Editorial Layout**:
The magazine-inspired visual and typographic system defined by Atelier Zero tokens, warm paper surfaces, and serial plate numbers.
_Avoid_: Dark glassmorphism, Neo-Obsidian theme

**Engineering Loop**:
The four-stage development methodology (Discovery, AI Coding, Testing, Deployment) demonstrating human-in-the-loop AI engineering.
_Avoid_: Development process, workflow steps

### Experience & Capability

**Professional Work**:
The enterprise track record at Greenpeace Taiwan covering web development, MarTech, troubleshooting, and automation.
_Avoid_: Employment history, career timeline, job experience

**Representative Pages**:
Live production campaign and fundraising pages developed for Greenpeace Taiwan (Online Donation and Ocean Petition).
_Avoid_: Sample pages, external demos, Greenpeace links

**Skills Matrix**:
The six structured technical capability groups and verified engineering tools, explicitly excluding standalone machine learning algorithms.
_Avoid_: Tech stack, skill list, skill ledger

**Credentials**:
Official industry certifications (such as the MOEA iPAS AI Application Planner) accompanied by verified document previews.
_Avoid_: Licenses, awards, diplomas

### Dynamic Systems

**Dynamic Project Pipeline**:
The live GitHub repository search, filtering, and pagination system fed by serverless API proxies.
_Avoid_: Repo list, static cards, project showcase
